# 15 — Сетка узлов для маппинга

Status: resolved
Type: grilling
Blocked by: 14
Spec: ../spec.md §5, §13.2

## Вопрос
Какие бакеты стека и сайзинга, какая метрика расстояния до узла и какой порог отсечения? Определяется тем, какие узлы реально покрыты выбранными чартами (тикет 14).

## Comments

**2026-10-01.** Нормализация (тикет 02) считает эффективный стек как «стек на начало раздачи минус анте, блайнды в стеке», а долю пота — по соглашению солверов (1.0 = пот-сайз рейз). При выборе чартов проверить, в каком соглашении указаны их стеки (40bb до или после анте/блайндов) и сайзинги; при расхождении — пересчёт в маппинге, а не в нормализации.

**2026-10-01.** Признаки регрессии (тикет 09) используют временные бакеты из `AnalysisConfig`: стек `<20 / 20-30 / 30-45 / 45+`, ставка, на которую отвечаем, `none / <2.5 / 2.5-3.5 / 3.5+`. После решения по сетке — заменить значениями по умолчанию из этой сетки.

**2026-10-01 — предложение (ждёт подтверждения).** Ключ узла — позиции + тип действия (`open` / `3bet` / `4bet` / `jam` / `call`); расстояние в лог-пространстве: d = √(d_stack² + Σ d_size²), d_stack = ln(eff/40)/σ, d_size = ln(факт/узел)/σ для каждого рейза до решения, σ = ln 1.25; вес w = exp(−d²/2), при w < 0.1 → weight = 0. Подробности — в ответе пользователю того же дня; после подтверждения перенести сюда в `## Answer`.

## Answer

**2026-10-01 — утверждено пользователем (Q1–Q5).**

1. **Ключ узла** — позиции + тип действия без размеров: `open`, `3bet`, `4bet`, `jam`, `call` (первый рейз — open, второй — 3bet, третий — 4bet; олл-ин-рейз — всегда jam). Сбросы и чеки в ключ не входят. Нет узла с таким ключом (лимп, открытие олл-ином, сквиз до появления чартов) — решение не сопоставляется и учитывается в отчёте маппинга.
2. **Стек:** `d_stack = ln(eff / S_узла) / σ`, σ = ln 1.25. Ближайший по стеку узел из узлов с тем же ключом. Сравнение в соглашении чарта: уплаченное анте добавляется обратно. BB-ante считается эквивалентным анте с каждого (мёртвых денег столько же).
3. **Сайзинг:** для каждого рейза до решения героя `d_size = ln(факт / узел) / σ`; jam против jam — 0. Текущий рейз героя в расстояние не входит.
4. **Вес:** `d = √(d_stack² + Σ d_size²)`, `w = exp(−d²/2)`; при `w < 0.1` → `weight = 0` (решение помечено, `distance` сохраняется). σ и порог входят в версию маппинга.
5. **Признаки регрессии:** «ставка, на которую отвечаем» — тип действия (`none / open / 3bet / 4bet / jam`); бакеты стека `<30 / 30-35 / 35-45 / 45+`.
