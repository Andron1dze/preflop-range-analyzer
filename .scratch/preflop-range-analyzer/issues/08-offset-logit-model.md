# 08 — Логистическая регрессия со смещением по дереву действий

Status: resolved

## Что сделать
- Дерево действий из конфига (шаги «продолжить/сбросить», «агрессия/колл»).
- Эталон на `statsmodels.GLM(offset, var_weights)`; своя реализация IRLS + L2 на numpy.
- Обрезка частот `[ε, 1−ε]`, исключение неопределённых условных вероятностей.

## Критерии приёмки
- На синтетике с заданными β обе реализации восстанавливают β; расхождение numpy vs statsmodels в пределах допуска (при L2 = 0).
- Доверительные интервалы пишутся в `model_coefs`.

## Comments

**2026-10-01 — реализовано (TDD).** 249 тестов зелёные; смещение в IRLS, сэндвич-SE и отсечение вырожденных шагов проверены мутациями.

- `core/models/offset_logit.py`:
  - `fit_statsmodels(X, y, offset, weights)` — эталон: `GLM(Binomial, offset, var_weights)`, `tol=1e-12`.
  - `fit_irls(X, y, offset, weights, l2=0, unpenalized=())` — numpy IRLS + L2; столбцы из `unpenalized` (свободный член) не штрафуются. SE: при L2 = 0 — обратная информация Фишера (совпадает со statsmodels до 1e-6, включая интервалы); при L2 > 0 — сэндвич A⁻¹·I·A⁻¹.
  - `save_coefs(session, run_id, tree_step, features, fit)` → `model_coefs`.
- `core/models/action_tree.py`: `DEFAULT_TREE` (`continue_vs_fold`, `aggr_vs_call`), `load_tree(config)` с валидацией, `step_dataset(step, decisions, eps)` → `rows, y, offset`. Условная частота обрезается до [ε, 1−ε]; строки исключаются, если частота не определена или шаг в узле вырожден (нет действий одной из сторон — например, «агрессия или колл» в RFI). `allin` считается агрессией.
- Тесты на синтетике: обе реализации восстанавливают заданные β; при игре по GTO β/se ~ N(0, 1) и покрытие 95%-интервалов ≈ 95% (200 симуляций); модель без смещения приписывает игроку зависимость GTO-частоты от признака (β ≈ 2 вместо 0); сэндвич-SE при L2 = 50 совпадает с эмпирическим разбросом в пределах ~12%.

Не сделано: построение матрицы признаков из `decisions` (позиция, бакеты стека/сайзинга, группа руки, зона, стадия) — в тикете 09 вместе с прогоном.
