## Что сделать
- Парсер строк вида `AA,AKs:0.5,KQo:0.25` (по одной строке на действие) → канонический формат чарта.

## Критерии приёмки
- Отсутствующая рука = частота 0; остаток до 1 уходит в fold, если так задано.
- Комбо-уровень (`AhKh:0.5`) агрегируется в класс руки по явному правилу (среднее по комбо класса).
- Результат проходит валидацию тикета 04.

## Comments

**2026-10-01 — реализовано (TDD).** 168 тестов зелёные; агрегация комбо проверена мутацией.

- `core/charts/importers/pio_range.py`:
  - `parse_range(text) → {класс: вес}` для всех 169 классов, отсутствующие — 0.
  - `strategy_from_ranges({действие: строка}, remainder="fold")` — остаток до 1 уходит в `remainder` (для BB против лимпа можно `check`); сумма действий > 1 — ошибка с именем руки.
  - `build_node(key, stack_bb, sizings, ranges)` — узел в каноническом формате; проверен через `parse_chart_set` (тикет 04).
- Синтаксис: `AA`, `AKs`, `AKo`, `AK` (обе масти), комбо `AhKh`, `22+`, `A2s+`, `ATo+`, `99-66`, `KTo-K8o`; вес `:w` ∈ [0, 1].
- **Комбо → класс:** средний вес по всем комбо класса (6 / 4 / 12). `AhKh:0.5` → `AKs = 0.125`.
- Одно комбо, указанное дважды (в т.ч. `AKs` и `AhKh`), — ошибка, а не перезапись.
