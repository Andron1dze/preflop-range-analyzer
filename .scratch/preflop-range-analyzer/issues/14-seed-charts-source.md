# 14 — Источник начальных GTO-чартов

Status: resolved
Type: grilling
Spec: ../spec.md §7, §13.1

## Вопрос
Из какого реального источника берём чарты для узлов MVP (RFI с UTG и BTN, защита BB против открытия с BTN; 40bb, 8-max, BB-ante)? Солвер, GTO Wizard, бесплатные чарты — с какой лицензией и в каком формате экспорта?

Частоты не придумываются: анализ мерит отклонения именно от этой стратегии. В тестах используются только синтетические чарты с `source: synthetic-test`.

## Answer

**2026-10-01.** Источник для MVP — HRC (Holdem Resources Calculator), ChipEV, 8-max, 40bb, анте 12.5% (0.125bb с каждого). Дерево сайзингов: открытие 2.0bb (SB 2.5bb); 3-бет IP 2.7x, OOP (не блайнды) 3.5x, с блайндов 4.0x; 4-бет 2.2x или олл-ин.

Файла экспорта HRC пока нет. Создан `charts/40bb_core.yaml` (UTG RFI, BTN RFI, BB против открытия BTN) с деревом сайзингов HRC и **приблизительными частотами по общему знанию** — поэтому `source: synthetic-test`: набор валиден, годится для разработки и демо, но в пользовательский анализ не попадает. Тест `tests/charts/test_repo_charts.py` проверяет, что все файлы в `charts/` валидны.

Следующий шаг: экспорт диапазонов из HRC (строки диапазонов по действиям) → `pio_range.build_node` → тот же файл с `source: hrc-chipev-40bb-8max`.
