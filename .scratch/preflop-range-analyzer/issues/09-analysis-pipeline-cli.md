## Comments

**2026-10-01 — реализовано (TDD), кроме команды `remap`.** 323 теста зелёные; фильтры пайплайна и откат упавшего прогона проверены мутациями.

- `core/analysis/config.py`: `AnalysisConfig` (stats, tree, l2 = 1.0, `stack_edges` = 20/30/45, `facing_edges` = 2.5/3.5, `features`), `to_dict` / `from_mapping` с валидацией, `load_config(yaml)`. Весь конфиг пишется в `analysis_runs.params`.
- `core/analysis/features.py`:
  - признаки: позиция, бакет эффективного стека, бакет размера ставки, на которую отвечаем (последний `R` в линии), группа руки, зона условной GTO-частоты шага, стадия (`unknown`, если нет);
  - one-hot со свободным членом; опорный уровень — первый присутствующий в данных в порядке UTG / номинальный стек 40bb / none / pair / mix / unknown — так свободный член не коллинеарен дамми, когда опорного уровня нет в данных;
  - `translate_action`: рейз-олл-ин → `allin`, если он есть в узле, иначе `raise` (и наоборот); действие, которого нет в узле, исключает решение.
- `core/analysis/pipeline.py`: `run_analysis(session, chart_set_id, mapping_version, config, allow_synthetic=False)`.
  - Берёт решения героя с `hand_class`, привязанные в `mapping_version` с весом > 0 к узлам выбранного набора.
  - Статистика: по каждому узлу и каждому его действию → `node_stats` (верхний уровень + зоны + группы); BH — по строкам верхнего уровня всего прогона, у остальных `bh_q = NULL`.
  - Регрессия: по каждому шагу дерева → `fit_irls(l2, свободный член без штрафа)` → `model_coefs`; шаг пропускается, если строк не больше, чем признаков.
  - Всё пишется в savepoint: упавший прогон помечается `failed` без частичных строк. Синтетические чарты отвергаются, если не передан `allow_synthetic` (пишется в `params`; CLI его не выставляет).
- Схема: `decisions.all_in` (нормализация его считала, но не сохраняла), `node_stats.action`; миграция `889149f41a73`. У раздач, импортированных до миграции, `all_in = 0` — нужен переимпорт.
- `cli/main.py`: `init-db` (alembic upgrade head), `import FILE --hero`, `load-charts FILE`, `analyze --chart-set --mapping-version [--config]`.

Не сделано: **`remap`** — маппинг решений на узлы (тикет 06) заблокирован сеткой узлов (тикет 15). Пайплайн читает готовый `decision_node_map`; в тестах он заполняется напрямую.

Замечание по интерпретации: признаки, жёстко связанные с узлом (позиция, сайзинг ставки, на которую отвечаем), коллинеарны, если в данных мало разных узлов; L2 держит модель устойчивой, но отдельные β в таком случае не идентифицируемы. Для чтения конкретного эффекта — прогон с подмножеством `features`.
