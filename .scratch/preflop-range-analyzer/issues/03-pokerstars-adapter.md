# 03 — Адаптер HH PokerStars

Status: resolved
Type: task
Blocked by: 02

## Что сделать
- Парсер текстовых HH PokerStars (турниры) → внутренняя модель раздачи; сырой текст сохраняется в `hands.raw_text`.
- Разделение файла на раздачи, определение героя по `hero_name` (параметр / профиль).

## Критерии приёмки
- Эталонные фрагменты HH: открытие, 3-бет, пуш, лимп, сайд-пот, анте → ожидаемая модель.
- Повторный импорт той же раздачи не создаёт дубликат.
- Неизвестный формат строки → понятная ошибка с номером раздачи, остальные раздачи импортируются.

## Comments

**2026-10-01 — реализовано (TDD).** 88 тестов зелёные; откат битой раздачи проверен мутацией.

- `core/adapters/pokerstars.py`: `parse_file(text, hero_name) → ParseResult(hands, errors)`, `parse_hand(raw, hero_name) → Hand`.
  - Разбивка файла по строкам `PokerStars Hand #`, BOM и CRLF допустимы; `raw_text` — текст одной раздачи.
  - Тип анте определяется по постам: только BB → `bb`, иначе `each`; нет постов → `none`.
  - Ники с пробелами: игрок определяется по самому длинному совпадающему нику из списка мест.
  - Пропускаются: чат, `doesn't show hand` / `mucks` / `shows`, `Uncalled bet`, `collected`, всё после префлопа. Игроки `out of hand` не входят в раздачу; `sitting out` — входят.
  - Нераспознанная строка игрока → `PokerStarsParseError` с номером раздачи; в `parse_file` она попадает в `errors`, остальные раздачи разбираются.
- `ParsedHand(hand, raw_text)` перенесён в `core/model` — общий результат для всех адаптеров (ручной ввод, тикет 11).
- `core/db/persist.py`: `import_hands(session, parsed, source) → ImportReport(imported, duplicates, errors)`. Дубликаты по `(source, external_id)` пропускаются, в т.ч. внутри одного файла; каждая раздача пишется в savepoint — упавшая на нормализации не оставляет строк.

Фикстуры (`tests/adapters/fixtures/`) синтетические, в формате PokerStars: RFI с анте у всех и 3-бет/пуш с BB-ante и пустым местом.

Не покрыто фикстурами из критериев приёмки: лимп и сайд-пот (по договорённости взяты две раздачи — RFI и 3-бет/пуш). Лимп разбирается как обычный `calls`, сайд-пот на префлоп-модель не влияет, но эталонных раздач на них пока нет.

Не сделано: Tournament Summary (тикет 13), мёртвый баттон, столы с >8 игроками (ошибка из позиций), карты соперников с шоудауна не сохраняются. Стоит добавить в фикстуры несколько настоящих раздач из своей базы — формат строк PokerStars местами менялся между годами.
